# メルカリちゃん

## 概要
LINEから商品情報を登録し、メルカリ出品作業を効率化するAI社員。

## 現在できること
- LINEリッチメニューから入力
- 商品情報登録
- Googleスプレッドシート保存
- 商品画像登録
- スマホ対応

## 使用技術
- LINE Messaging API
- Google Spreadsheet
- Vercel
- GitHub
- JavaScript

## フォルダ構成
```bash
uploads/   # 商品画像
outputs/   # 出力データ
prompts/   # AI用プロンプト
docs/      # マニュアル
```

## 今後追加したい機能
- 商品説明自動生成
- AI商品画像生成
- CSV出力
- 出品管理
- 売上分析

## 現在の課題
